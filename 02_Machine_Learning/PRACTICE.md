## ★ 코어 자료 가이드
### A Few Useful Things to Know About Machine Learning
[DOI](https://doi.org/10.1145/2347736.2347755)

- **이 논문이 답하는 질문:** 교과서에 잘 안 나오지만 ML을 실제로 쓸 때 반드시 알아야 하는 것은 무엇인가.
- **읽기 가이드:** 12개 교훈의 소제목만 먼저 훑고, 각 교훈을 "내가 겪은(또는 Lab에서 본) 사례" 한 줄과 짝짓는다. 실험이 없는 에세이형 논문이라 주장-증거 표의 증거 칸에는 "예시·논증"이 들어간다.
- **실습:** Lab 01 전체. 특히 1절(과적합)과 3절(누수).

**기억 점검**
1. "학습 = 표현 + 평가 + 최적화"는 무슨 뜻인가?
2. 저자가 알고리즘보다 중요하다고 한 것 두 가지는?
3. test 데이터로 하이퍼파라미터를 고르면 왜 안 되나?

<details><summary>답 확인</summary>

1. 모든 학습 알고리즘은 가설을 표현하는 방식, 좋고 나쁨을 재는 평가 함수, 가장 좋은 것을 찾는 최적화 방법의 조합이다.
2. 피처 엔지니어링, 그리고 더 많은 데이터.
3. test가 더 이상 '본 적 없는 데이터'가 아니게 되어 일반화 성능이 과대평가된다.
</details>

### XGBoost: A Scalable Tree Boosting System
[arXiv 1603.02754](https://arxiv.org/abs/1603.02754)

- **이 논문이 답하는 질문:** 트리 부스팅을 어떻게 정규화하고, 수십억 건까지 빠르게 돌릴 것인가.
- **읽기 가이드:** 초록에 정확도 숫자가 없다 → **시스템 논문**이다. 2절(정규화된 목적함수 → 2차 근사 → 분할 이득 식)을 [워크북](../00_Foundations/10_paper-reading-workbook.md)의 수식 읽기 4단계로 읽고, 3절(근사 분할·희소성 처리)과 4절(시스템)은 "무엇을 빠르게 하려는가"만 잡는다. 실험 절의 그림은 y축이 시간인지 정확도인지부터 확인.
- **실습:** Lab 02의 3절(이득 식을 손으로 계산)과 4절(조기 종료).

**기억 점검**
1. 분할 이득 식의 λ와 γ의 역할은?
2. 왜 2차 근사(기울기 g와 헤시안 h)를 쓰나?
3. sparsity-aware 분할이란?

<details><summary>답 확인</summary>

1. λ는 잎 값에 대한 L2 벌점, γ는 잎을 하나 늘리는 비용(이득이 γ보다 작으면 나누지 않음).
2. 임의의 미분 가능한 손실에 대해 같은 형태의 잎 값·이득 공식을 얻을 수 있어서.
3. 결측·0 값을 보낼 기본 방향을 데이터에서 학습해, 존재하는 값만 훑어 분할을 찾는 방법.
</details>

### A Unified Approach to Interpreting Model Predictions (SHAP)
[arXiv 1705.07874](https://arxiv.org/abs/1705.07874)

- **이 논문이 답하는 질문:** 여러 설명 기법을 하나의 틀로 묶을 수 있는가, 그 틀에서 '유일하게 타당한' 기여도는 무엇인가.
- **읽기 가이드:** "가법적 특성 기여(additive feature attribution)" 정의 → 세 성질(local accuracy, missingness, consistency) → 그것을 만족하는 유일한 해가 Shapley 값이라는 흐름만 따라간다. 근사 알고리즘 세부는 건너뛴다.
- **실습:** Lab 02의 5절(가법성 확인, 의존성 그림)과 직접 해보기 3(상관된 특성).

**기억 점검**
1. local accuracy란?
2. SHAP 값이 크면 그 특성이 결과의 원인인가?

<details><summary>답 확인</summary>

1. 기준값 + 각 특성의 기여도 합 = 그 표본의 모델 출력.
2. 아니다. 모델의 계산을 분해한 것일 뿐 인과 효과가 아니다. 상관된 특성이 있으면 기여도가 나뉜다.
</details>
