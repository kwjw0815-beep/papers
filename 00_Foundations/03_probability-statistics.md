# 확률·통계 (Probability & Statistics)

## 왜 필요한가
데이터에는 항상 **우연(잡음)**이 섞여 있다. 통계는 "이 차이가 진짜인가, 우연인가"를 판단하는 언어다. 논문의 Results 절(README의 6번 질문 "통계 검정과 결과")을 읽으려면 필수이고, A/B 테스트·면접에서 가장 자주 묻는다.

## 최소한 이것만
| 개념 | 직관 | 정의 |
|---|---|---|
| 확률변수 | 결과가 우연히 정해지는 숫자 | $X$ |
| 분포 (distribution) | 어떤 값이 얼마나 자주 나오는가 | 정규, 베르누이, 이항, 포아송 … |
| 기댓값 / 분산 | 평균적인 값 / 평균에서 퍼진 정도 | $E[X]$, $Var(X)=E[(X-E[X])^2]$ |
| 조건부 확률 | B를 알고 있을 때 A의 확률 | $P(A\mid B)=P(A\cap B)/P(B)$ |
| 베이즈 정리 | 증거를 보고 믿음을 갱신 | $P(H\mid D)=\frac{P(D\mid H)P(H)}{P(D)}$ |
| 표본 vs 모집단 | 우리가 가진 데이터 vs 알고 싶은 전체 | 표본평균 $\bar x$로 모평균 $\mu$를 추정 |
| 표준오차 (SE) | **추정치**가 표본마다 흔들리는 정도 | $SE=\sigma/\sqrt{n}$ (표준편차와 다름!) |
| 중심극한정리 (CLT) | 표본이 크면 평균의 분포는 정규분포에 가까워짐 | 검정·신뢰구간의 근거 |
| 신뢰구간 (CI) | 추정의 불확실성 범위 | 95% CI ≈ $\bar x \pm 1.96\,SE$ |

## 가설검정 한 번에 정리
1. **귀무가설 $H_0$**: "차이가 없다". **대립가설 $H_1$**: "차이가 있다".
2. 데이터로 검정통계량(t, z, χ² …)을 계산.
3. **p-value** = $H_0$가 참일 때 이만큼(또는 더) 극단적인 결과가 나올 확률.
4. p < 유의수준 $\alpha$(보통 0.05)이면 $H_0$ 기각.

| | $H_0$ 참 | $H_0$ 거짓 |
|---|---|---|
| 기각 | 1종 오류 (false positive, 확률 $\alpha$) | 옳음 (검정력 power = $1-\beta$) |
| 기각 못 함 | 옳음 | 2종 오류 (false negative, 확률 $\beta$) |

**p-value에 대한 흔한 오해** (ASA Statement 참고)
- ✗ "p=0.03이면 귀무가설이 참일 확률이 3%" → p-value는 가설의 확률이 아니다.
- ✗ "p<0.05면 효과가 크다" → 표본이 크면 아주 작은 효과도 유의해진다. **효과 크기와 신뢰구간**을 함께 본다.
- ✗ "p>0.05면 효과가 없다" → 증거가 부족할 뿐이다.

## 한 단계 더
- **최대우도추정 (MLE):** 관측된 데이터가 가장 그럴듯해지는 파라미터를 고른다. 로지스틱 회귀의 cross-entropy 손실 = 음의 로그우도.
- **선형회귀:** $y=X\beta+\varepsilon$. 계수 = "다른 변수를 고정했을 때 x가 1 늘면 y가 얼마나 변하는가".
- **부트스트랩:** 데이터를 복원추출로 여러 번 다시 뽑아 추정치의 분포를 시뮬레이션. 공식이 없어도 신뢰구간을 구할 수 있다.
- **다중검정:** 검정을 20번 하면 우연히 1번은 유의하게 나온다 → Bonferroni, Benjamini-Hochberg(FDR)로 보정.
- **베이지안 vs 빈도주의:** 파라미터를 확률변수로 보느냐(사전분포→사후분포), 고정된 미지수로 보느냐.
- **엔트로피·KL divergence:** 불확실성의 양 / 두 분포의 차이. cross-entropy 손실, VAE, 디퓨전 논문에 나온다.

## 논문에서 만나는 모습
| 표현 | 뜻 |
|---|---|
| "± 0.3", error bar | 표준편차인지 표준오차인지 95% CI인지 **캡션을 꼭 확인** |
| "statistically significant (p<0.01)" | 우연이라고 보기 어려움. 효과 크기는 별도로 확인 |
| "averaged over 5 seeds" | 랜덤 시드를 바꿔 반복 — 차이가 시드 변동보다 큰지 볼 것 |
| $\mathbb{E}_{x\sim p}[\cdot]$ | 분포 p에서 뽑은 x에 대한 기댓값 (실제로는 표본 평균으로 근사) |
| "i.i.d." | 독립이고 같은 분포에서 나옴. 시계열·추천에서는 자주 깨진다 |
