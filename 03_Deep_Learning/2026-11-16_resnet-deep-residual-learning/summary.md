- **자료 유형:** 논문
- **정리일:** 2026-11-16
- **읽은 단계:** 3차(재구성)까지 — 핵심 현상을 작은 실험으로 재현함
- **한 줄 요약:** 층을 깊게 쌓으면 *학습 오차부터* 나빠지는 문제를, 입력을 그대로 더해 주는 지름길(`y = x + F(x)`) 하나로 해결해 152층까지 학습시켰다.

## 0. 1차 읽기 메모 (5~10분, 훑으면서 바로 적은 것)

- **무엇을 풀려는 논문인가:** 신경망을 깊게 만들수록 학습이 어려워지는 문제.
- **핵심 아이디어 (이 시점의 추측):** 층이 원하는 함수 H(x)를 직접 배우게 하지 말고, 입력과의 차이 F(x) = H(x) − x 를 배우게 한다. 그림 2의 "x를 건너뛰어 더하는 화살표"가 전부인 듯.
- **가장 중요한 그림/표:** Figure 1(56층이 20층보다 *학습* 오차가 높다 → 문제 제기), Figure 2(잔차 블록 → 해결책), Table 2 + Figure 4(plain vs ResNet → 증거).
- **모르는 말:** degradation, shortcut connection, bottleneck, 10-crop testing, FLOPs.
- **계속 읽을 것인가:** 읽는다. 문제-해결-증거가 그림 세 개로 연결되어 있고, 거의 모든 최신 모델(Transformer 포함)이 이 구조를 쓴다.

## TL;DR (3줄)
1. **문제:** 층을 늘리면 정확도가 포화되다가 오히려 떨어진다. 과적합이 아니다. 학습 오차 자체가 더 높다(degradation).
2. **방법:** 몇 개 층마다 입력을 출력에 그대로 더하는 지름길을 둔다. 층은 "잔차" F(x)만 배운다. 추가 파라미터가 없다.
3. **결과:** 같은 깊이·같은 파라미터 수에서 plain 망은 깊을수록 나빠지고 ResNet은 깊을수록 좋아진다. 152층 모델과 앙상블로 ILSVRC 2015 분류 1위(top-5 오차 3.57%).

## 논문 읽기 질문 (README 기준)

1. **선행 연구:** 이 논문이 기반으로 삼은 이전 연구와 아이디어는?
   - VGG(작은 3×3 필터를 깊게 쌓는 설계)를 plain 기준 모델의 출발점으로 삼았다.
   - Batch Normalization과 He 초기화 덕분에 수십 층짜리 망이 "수렴을 시작"할 수 있게 된 상태였다. 그 다음에 드러난 문제가 degradation이다.
   - 지름길 연결 자체는 새 발상이 아니다. 같은 시기의 Highway Networks는 지름길에 **게이트**(학습되는 가중치)를 달았고, ResNet은 게이트 없는 **항등** 지름길을 쓴다는 점이 다르다고 저자들이 Related Work에서 구분한다.

2. **연구 동기:** 왜 이 연구를 했는가?
   - "더 깊은 망이 더 좋다"는 것이 ImageNet 결과들로 분명해졌는데, 단순히 층을 더 쌓으면 정확도가 포화된 뒤 **급격히 나빠졌다.**
   - 이상한 점: 얕은 망에 층을 추가한 깊은 망은, 추가한 층이 항등 함수이기만 해도 얕은 망과 똑같이 할 수 있다. 그러니 학습 오차가 더 높을 이유가 없다. 그런데 실제로는 더 높다 → 현재의 최적화 방법이 그 해를 찾지 못한다.

3. **연구 목표:**
   - degradation 문제를 해결하는 학습 구조(잔차 학습)를 제안한다.
   - 그 구조가 (a) 최적화하기 쉽고 (b) 깊이를 늘릴수록 정확도가 오른다는 것을 실험으로 보인다.

4. **사용 장비/소프트웨어/데이터셋:**
   - 데이터: ImageNet 2012 분류(학습 128만 장, 검증 5만 장, 1000 클래스), CIFAR-10, 그리고 탐지 실험용 PASCAL VOC·MS COCO.
   - 학습 설정(ImageNet): SGD, 미니배치 256, 학습률 0.1에서 시작해 오차가 정체되면 1/10, 최대 60만 iteration, weight decay 0.0001, momentum 0.9, 드롭아웃 없음. 모든 합성곱 뒤·활성화 앞에 BatchNorm.
   - 계산량 비교 단위: FLOPs(곱셈-덧셈 횟수). VGG-19는 196억, 34층 plain/ResNet은 36억, ResNet-152는 113억.

5. **측정 변수:**
   - 독립 변수: 깊이(18/34/50/101/152층, CIFAR에서는 20~1202층), 지름길의 유무, 지름길의 종류(A: 0 채우기, B: 차원이 바뀔 때만 1×1 합성곱, C: 전부 1×1 합성곱).
   - 종속 변수: 학습 오차와 검증 오차(top-1, top-5), 그리고 층 출력의 표준편차(Figure 7).
   - 통제: plain과 ResNet은 깊이·폭·파라미터 수·계산량이 같다(옵션 A 사용). **다른 것은 지름길뿐**이다. 이 통제가 이 논문 실험의 핵심이다.

6. **통계 검정 및 결과:**
   - 통계적 검정이나 신뢰구간은 없다. ImageNet 결과는 대부분 **한 번의 학습**에서 나온 숫자다.
   - 예외: CIFAR-10의 ResNet-110은 5번 학습해 "최고값 (평균 ± 표준편차)" = 6.43% (6.61 ± 0.16)으로 보고했다.
   - 판단: 핵심 비교(plain-34 28.54% vs ResNet-34 25.03%)는 차이가 3.5%p로 크고 학습 곡선 전체에서 일관되므로 시드 변동으로 설명하기 어렵다. 반대로 지름길 옵션 A/B/C처럼 0.3~0.5%p 차이인 비교는 반복 실험이 없어 순위를 단정하기 어렵다.

7. **주요 발견:**
   - **plain 망은 깊을수록 나쁘다:** top-1 오차 18층 27.94% → 34층 28.54% (Table 2). 학습 오차도 34층이 더 높다(Figure 4 왼쪽).
   - **ResNet은 깊을수록 좋다:** 18층 27.88% → 34층 25.03%. 34층에서 plain 대비 3.5%p 개선.
   - 18층에서는 plain과 ResNet의 정확도가 비슷하지만 ResNet이 **더 빨리 수렴**한다. 즉 지름길은 "충분히 깊지 않을 때"는 속도를, 깊을 때는 도달 가능한 오차를 개선한다.
   - 병목(bottleneck) 블록으로 50/101/152층까지 늘리면 계속 좋아진다. ResNet-152 단일 모델의 top-5 검증 오차는 4.49%로, 이전의 모든 앙상블 결과보다 낮다. 6개 모델 앙상블은 테스트 top-5 오차 3.57%.
   - CIFAR-10: 110층 6.43%. 1202층도 학습은 되지만(학습 오차 0.1% 미만) 테스트 오차는 7.93%로 110층보다 나쁘다 → 저자들은 과적합으로 해석.

8. **분야 내 위치:**
   - "깊이를 늘릴 수 없다"는 병목을 없앤 논문. 이후 비전 모델의 기본 뼈대가 되었고, Transformer의 모든 블록에도 같은 잔차 연결(`x + Sublayer(x)`)이 들어간다.
   - 탐지에서도 VGG-16을 ResNet-101로 바꾸는 것만으로 COCO에서 상대 28% 개선을 보고해, "좋은 표현(backbone)이 여러 과제에 전이된다"는 흐름을 굳혔다.

9. **Figure 설명:**
   - **Figure 1:** CIFAR-10에서 20층과 56층 plain 망의 학습/테스트 오차. 56층이 **두 곡선 모두** 더 높다. → 문제의 정의. "과적합이 아니다"라는 주장의 근거가 왼쪽(학습 오차) 그림이다.
   - **Figure 2:** 잔차 블록. 두 개의 가중치 층을 지나는 경로 F(x)와, 입력 x를 그대로 넘기는 경로를 더한 뒤 ReLU. → 해결책 전체가 이 그림 하나.
   - **Figure 3 / Table 1:** VGG-19, 34층 plain, 34층 ResNet의 구조 비교. 점선 지름길은 차원이 바뀌는 곳.
   - **Figure 4:** ImageNet 학습 곡선. 가는 선이 학습 오차, 굵은 선이 검증 오차. 왼쪽(plain)은 34층 선이 18층 선 **위에**, 오른쪽(ResNet)은 34층 선이 **아래에** 있다. → 이 논문에서 가장 중요한 증거.
   - **Figure 5:** 기본 블록(3×3, 3×3)과 병목 블록(1×1, 3×3, 1×1). 병목은 계산량을 유지하면서 깊이를 늘리기 위한 설계.
   - **Figure 6:** CIFAR-10 학습 곡선. plain은 깊을수록 나빠지고(110층은 오차 60% 초과로 그림에서 제외), ResNet은 깊을수록 좋아진다.
   - **Figure 7:** 층 출력의 표준편차. ResNet의 값이 plain보다 전반적으로 작다. → "잔차 함수는 0에 가깝다"는 동기를 뒷받침하는 보조 증거.

11. **저자, 연도, 제목:** Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun. 2015. *Deep Residual Learning for Image Recognition*.

12. **저자 배경:**
    - 같은 저자들이 He 초기화·PReLU(*Delving Deep into Rectifiers*, 2015)와 Faster R-CNN(2015)을 썼다. 이 논문의 초기화와 탐지 실험이 그 연장선이다.
    - 후속작 *Identity Mappings in Deep Residual Networks* (2016)에서 블록 안의 순서를 바꾼 pre-activation 구조로 1001층까지 확장했다.

13. **모르는 용어/개념:**
    | 용어 | 설명 |
    |---|---|
    | degradation | 층을 늘렸을 때 **학습 오차까지** 나빠지는 현상. 과적합(학습 오차는 좋아짐)과 구별된다 |
    | residual / shortcut (skip) connection | 잔차 F(x) = H(x) − x / 입력을 몇 층 건너뛰어 그대로 더하는 연결 |
    | identity mapping | 입력을 그대로 내보내는 함수. 지름길이 이것이면 파라미터가 늘지 않는다 |
    | bottleneck block | 1×1로 채널을 줄이고 → 3×3 → 1×1로 다시 늘리는 3층 블록 |
    | top-1 / top-5 error | 1순위 예측이 틀린 비율 / 상위 5개 예측 안에 정답이 없는 비율 |
    | 10-crop testing | 이미지 한 장에서 10개 조각을 잘라 예측을 평균하는 평가 방식 |
    | FLOPs | 계산량의 척도(여기서는 곱셈-덧셈 횟수) |
    | plain network | 지름길이 없는, 층을 그냥 쌓은 망 (이 논문의 비교 기준) |

14. **나의 생각:**
    - **설득력 있는 부분:** 통제가 깔끔하다. plain과 ResNet은 지름길 하나만 다르고 파라미터 수가 같다. 그리고 최종 숫자만이 아니라 **학습 곡선**을 보여 줘서 "최적화가 쉬워졌다"는 주장을 직접 뒷받침한다.
    - **주장과 증거의 간격:** "왜" degradation이 생기는지는 밝히지 못했다. 저자들은 BatchNorm 덕분에 순전파·역전파 신호가 사라지지 않음을 확인했다며 기울기 소실을 원인에서 배제하고, "깊은 plain 망은 수렴 속도가 지수적으로 느릴 수 있다"는 **추측**만 남긴다. 현상과 해결책은 확실하지만 원인은 열린 질문이다.
    - **한계:** ImageNet 실험이 대부분 1회 학습이라 작은 차이(지름길 옵션 A/B/C)는 해석에 주의가 필요하다. 1202층 결과를 "과적합"으로 설명한 것도 추가 실험 없이 제시한 해석이다.
    - **지금 시점에서의 보완:** *ResNet strikes back* (2021)은 학습 절차만 현대화해도 같은 ResNet-50이 훨씬 높은 정확도를 낸다고 보고한다. 즉 "구조의 효과"와 "학습 레시피의 효과"는 섞이기 쉽고, 논문 간 숫자를 그대로 비교하면 안 된다.

## 데이터사이언티스트 관점 Takeaway
- **실무 적용 포인트:** train 곡선과 valid 곡선을 **둘 다** 그린다. 모델을 키웠는데 train 손실부터 나쁘면 과적합 대책(정규화, 데이터 추가)이 아니라 최적화 대책(구조, 학습률, 정규화 층)을 봐야 한다.
- **실험 설계에서 배울 점:** 주장하려는 요소 하나만 다르고 나머지(파라미터 수, 계산량, 학습 설정)가 같은 비교군을 만든다. 논문을 읽을 때도 "베이스라인과 무엇이 다른가"를 표로 정리해 본다.
- **면접/포트폴리오에 쓸 수 있는 포인트:** "과적합과 degradation의 차이를 무엇으로 구별하는가", "잔차 연결이 왜 Transformer에도 있는가"를 그림 없이 2분 안에 설명할 수 있어야 한다.

2. y = F(x) + x. 최적의 변환이 항등에 가깝다면 층들은 F(x) = 0만 배우면 된다(가중치를 0 쪽으로 보내기). 여러 비선형 층으로 항등 함수를 직접 만드는 것보다 쉽다.
3. plain은 18층(27.94%)보다 34층(28.54%)이 나쁘고, ResNet은 18층(27.88%)보다 34층(25.03%)이 좋다 — 지름길이 있어야 깊이가 이득이 된다.
4. plain 망도 BatchNorm을 써서 순전파 신호의 분산이 0이 아니고, 역전파 기울기의 크기도 정상임을 확인했다고 한다. 또 34층 plain도 꽤 괜찮은 정확도에는 도달한다.
5. 50층 이상으로 늘릴 때 학습 시간(계산량)을 감당하기 위해. 1×1 합성곱으로 채널을 줄였다 늘려서 3×3 합성곱의 비용을 낮춘다.
